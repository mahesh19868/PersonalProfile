# Personal portfolio — Next.js

Professional site for **Subramaniam Ananthakrishnan**.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS v4
- Framer Motion

Content sourced from `LinkedInProfile.pdf`. Update copy in `src/data/profile.ts`.
